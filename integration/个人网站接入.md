## 二、预览组件（src/App.jsx）

在 `ProjectPreview` 的分支里加一行：

```jsx
{kind === "fpa" && <FpaPreview />}
```

新写一个 `FpaPreview`，沿用现有 `LishiPreview` 的画法（viewBox `0 0 560 380`、面板 `rect x=8 y=8 w=544 h=364 rx=14`、样式类 `pv-panel` / `pv-side-title` / `pv-mono pv-faint` / `pv-node-label`）：

```jsx
function FpaPreview() {
  const bars = [
    { name: "红", y: 112, w: 196, color: "#D4594A" },
    { name: "蓝", y: 158, w: 158, color: "#4A6FA5" },

    { name: "绿", y: 250, w: 62, color: "#3A8E6A" }

  const steps = [
    { t: "30 道题 · 凭第一感觉选" },

    { t: "出主色、辅色与四色占比" },
    { t: "优势、过当、协作与职业方向" }
  ];
  return (
    <svg viewBox="0 0 560 380" className="pv-svg" role="img" aria-label="性格色彩测评预览">
      <rect x="8" y="8" width="544" height="364" rx="14" className="pv-panel" />

      <text x="30" y="76" className="pv-mono pv-faint">30 题 · 红蓝黄绿 · 出完整解析</text>

      {bars.map((b) => (
        <g key={b.name}>
          <text x="30" y={b.y - 8} className="pv-node-label" fontSize="12">{b.name}色</text>
          <rect x="30" y={b.y} width={b.w} height="24" rx="6" fill={b.color} opacity="0.9" />

      {steps.map((s, i) => (
        <g key={s.t}>

        </g>
      ))}
    </svg>
  );
}
```

## 三、两种挂法，二选一

### A. 只挂仓库链接（推荐）

就是上面那段的 `link.href` 指向 GitHub。好处是主站不承载讲义内容——`data/colors.json` 是 FPA® 培训讲义原文，挂到公开站点上有商标风险，仓库里有 NOTICE 声明兜着，主站不碰最稳。

### B. 主站直接托管在线版

把 `web/` 整个目录放到服务器，比如 `/usr/share/nginx/html/fpa/`（和现有 `/lishi/` 同级），然后把 `link` 改成：

```js
link: { href: "/fpa/index.html", label: "在线测试" }
```

`web/` 是纯静态、零构建，放上去就能跑，不需要在服务器上装任何东西。

## 四、部署前要确认的三件事

1. **要不要公开解析内容**：讲义含 FPA® 商标，公开托管前请确认授权。只挂仓库链接的话风险小很多。
2. **主站源码在哪**：这台机器上没找到主站源码（只有线上构建产物）。补丁代码已写好，给我源码路径就能直接改。
3. **部署动作**：按规矩不自主部署。你说一声，我再执行打包上传。
