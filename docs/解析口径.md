## 二、色彩对应关系怎么定的

PPT 第 10、12、13、29 页的四个文字分组**没有标色彩名称**，靠排列顺序判断不可靠。这里改读形状的填充色来定：

| 填充色 | 色彩 |
|--------|------|
| `FF0000` | 红 |
| `0099FF` | 蓝 |
| `FFCC00` | 黄 |
| `339966` | 绿 |

这四页的四组顺序统一是 **黄 → 绿 → 红 → 蓝**。

> 这一步不能靠猜：第 10 页「沟通」那组，凭语义很容易把红和绿判反（"让他们知道你高兴"看着像红，实际是绿）。按填充色定死才可靠。

其余页面（2-9、11、14-17、21-28）本身带色彩标题或按红蓝黄绿顺序排列，直接对应。

## 三、第 22 页的说明（曾误判为存疑，已更正）

第 22 页整页标题为「**红色对团队的贡献**」，讲的是**红色个体对团队的贡献分析**，
三行分别是三种状态下的表现，不是把别色内容贴错了：

| 行 | 内容 |
|------|------|
| 发挥优势时 | 提供帮助和指导给有需要的人 / 强烈拥护团队和组织的价值观与目标 / 设下很美好的远景并全力以赴 |
| 优势过当时 | 严密控制 / 全面的程序条理和方法 / 付诸逻辑事实和系统 |
| 运用优势得当时 | 愿意培训属下和团队成员 / 对环境的压力和要求很敏感 / 提供帮助给组织内外的人 / 自告奋勇的积极团队奉献者 |

2026-09-17 我曾按"红色过当应该是情绪波动/缺少秩序"把它判为疑似贴错，这个判断不成立——
这页是红色贡献的整页分析，行与行之间不是同一维度的对照。**原文照录，不做修改。**

## 四、选项与色彩的对应

题库每题四个选项，固定映射：

| 选项 | 色彩 | colors.json 的 key |
|------|------|--------------------|
| A | 红 | `red` |
| B | 蓝 | `blue` |
| C | 黄 | `yellow` |
| D | 绿 | `green` |

改题库时不要打乱这个顺序，否则计分会全错。

## 五、改动流程

1. 改 `data/colors.json` 或 `data/questions.json`
2. 跑 `python3 scripts/build.py`
3. 打开 `web/index.html` 验证
4. 如果是内容校正，同步更新本文档的「存疑项」
