## 二、色彩对应关系怎么定的

PPT 第 10、12、13、29 页的四个文字分组**没有标色彩名称**，靠排列顺序判断不可靠。这里改读形状的填充色来定：

| 填充色 | 色彩 |
|--------|------|
| `FF0000` | 红 |
| `0099FF` | 蓝 |
| `FFCC00` | 黄 |
| `339966` | 绿 |

这四页的四组顺序统一是 **黄 → 绿 → 红 → 蓝**。

> 这一步不能靠猜：第 10 页「沟通」那组，凭语义很容易把红和绿判反（"让他们知道你高兴"看着像红，实际是绿）。按填充色定死才可靠。

其余页面（2-9、11、14-17、21-28）本身带色彩标题或按红蓝黄绿顺序排列，直接对应。

## 三、存疑项（未擅自改动）

**第 22 页「红色对团队的贡献 · 发挥优势过当时」** 原文是：

> 严密控制 / 全面的程序条理和方法 / 付诸逻辑事实和系统

这与红色性格的过当特征（情绪波动、缺少秩序、难以兑现）明显不符，反而更接近蓝色的描述。蓝色页（第 23 页）同一行是"所有问题考虑前不愿采取行动 / 原则性太强，不易妥协"，才像是蓝色自己的。

判断：PPT 原文如此，可能是制作者贴错。**当前按原文照录，未做校正**。若要修正，改 `data/colors.json` 里 `red.teamContribution.whenOveruse` 即可。

## 四、选项与色彩的对应

题库每题四个选项，固定映射：

| 选项 | 色彩 | colors.json 的 key |
|------|------|--------------------|
| A | 红 | `red` |
| B | 蓝 | `blue` |
| C | 黄 | `yellow` |
| D | 绿 | `green` |

改题库时不要打乱这个顺序，否则计分会全错。

## 五、改动流程

1. 改 `data/colors.json` 或 `data/questions.json`
2. 跑 `python3 scripts/build.py`
3. 打开 `web/index.html` 验证
4. 如果是内容校正，同步更新本文档的「存疑项」
